# Генератор цитат

**Автор:** [Ваше ФИО]

## Описание

Приложение для генерации случайных цитат с возможностью фильтрации по автору и теме. Сохраняет историю сгенерированных цитат в JSON‑файл.

## Функциональность

* Генерация случайной цитаты по нажатию кнопки.
* Фильтрация цитат по автору и теме.
* Отображение истории сгенерированных цитат в виде таблицы.
* Сохранение истории в JSON‑файл (`history.json`).
* Загрузка цитат из JSON‑файла (`quotes.json`).
* Валидация ввода данных.
* Обработка исключений.

## Требования

* Python 3.6+
* Стандартные библиотеки: `tkinter`, `json`, `random`, `os`

## Инструкция по запуску

1. Убедитесь, что установлен Python 3.6+.
2. Скачайте все файлы проекта в одну папку.
3. Запустите приложение командой:
   ```bash
   python main.py
