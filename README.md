# Weather Diary (Дневник погоды)

**Автор:** [Кулик Максимов]

## Описание программы

Weather Diary — это GUI‑приложение для ведения дневника погоды. Приложение позволяет:

* добавлять записи о погоде с указанием даты, температуры, описания и наличия осадков;
* просматривать все записи в виде таблицы;
* фильтровать записи по дате и температуре;
* сохранять данные в JSON‑файл;
* загружать данные из JSON‑файла при запуске.

## Требования

* Python 3.6 или выше;
* стандартная библиотека Tkinter (входит в состав Python).
